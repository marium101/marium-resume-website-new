# Marium Rehman — Personal Resume Website

## 📌 Project Information

### Project Name

**Marium Rehman — Personal Resume Website**

### Project Description

A modern, responsive personal resume website developed using **HTML5 and CSS3**. The website presents my academic background, technical skills, projects, certifications, achievements, and professional interests through a clean and visually engaging web interface.

The website is designed from scratch without using Bootstrap, Tailwind CSS, ready-made templates, or JavaScript.

### Purpose of the Project

The purpose of this project is to transform a traditional resume into a modern, responsive web experience while demonstrating practical knowledge of **HTML5, CSS3, responsive design, layout systems, animations, and modern UI techniques**.

### Target Audience

This website is intended for:

- Recruiters
- Potential employers
- Clients
- Academic instructors
- Fellow developers
- Students and technology enthusiasts

## 🎨 Design Architecture

The website is organized into separate semantic sections to create a clear and maintainable structure.

### HTML Structure

The main HTML document contains the following sections:

1. Navigation
2. Hero / Profile
3. About Me
4. Education
5. Technical Skills
6. Projects
7. Academic & Practical Experience
8. Certifications & Achievements
9. Currently Learning
10. Contact
11. Footer

The HTML structure is maintained in the `index.html` file.

### CSS Architecture

All visual styling is maintained in the external `style.css` file.

CSS custom properties are used to maintain a consistent visual theme, including:

- Background colors
- Card colors
- Text colors
- Accent colors
- Borders
- Border radius
- Shadows

### Layout System

**CSS Grid** is used for structured layouts such as:

- Project cards
- Skill cards
- Hero section
- Achievement layouts

**CSS Flexbox** is used for:

- Navigation
- Alignment
- Buttons
- Content positioning

### Responsive Design

The website uses CSS media queries to adapt the layout for different screen sizes:

- **Desktop:** 1024px and above
- **Tablet:** 600px–1024px
- **Mobile:** below 600px

The layout automatically adjusts columns, spacing, typography, navigation, images, and cards according to the available screen size.

### Responsive Typography

CSS `clamp()` is used for fluid typography so that headings and other elements scale smoothly across different devices.

### Animations

Custom CSS `@keyframes` animations are used to create subtle visual movement, including:

- Profile image floating animation
- Heading entrance animation
- Decorative element rotation
- Animated visual effects

No JavaScript is required for these interactions.
