# Marium Rehman — Personal Resume Website

## Project Description

A modern and responsive personal resume website created to present
my academic background, technical skills, projects, certifications,
achievements, and professional interests through a web-based interface.

The website is built entirely using HTML5 and CSS3 without JavaScript.

## Purpose

The purpose of this project is to transform a traditional resume into
an interactive, responsive, and visually engaging web experience while
demonstrating practical knowledge of modern HTML and CSS techniques.

## Target Audience

This website is designed for:

- Recruiters
- Potential employers
- Academic instructors
- Clients
- Fellow developers and students

- Animated profile section

## Technologies Used

- HTML5
- CSS3

## Design Architecture

The website is structured using semantic HTML5 sections including
navigation, hero/profile, about, education, skills, projects,
experience, achievements, and contact.

All styling is maintained in an external `style.css` file.

CSS custom properties are used to maintain consistent colors,
spacing, borders, and visual styling throughout the website.

CSS Grid is used for project and skill layouts, while Flexbox is used
for navigation and alignment.

Responsive media queries are implemented for tablet and mobile
screen sizes.

Responsive typography is implemented using CSS `clamp()`.
